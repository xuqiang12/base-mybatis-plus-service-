# base-common：公共基础

记住一句话：**让各个服务用同样的方式处理请求、返回结果和报错。**

这是公共类库，不单独启动、不占端口，由需要它的服务引用。

| 负责什么 | 例子 |
| --- | --- |
| 统一返回 | 接口都返回 `code/message/data` |
| 分页结构 | 列表返回数据、总条数、页码、每页条数 |
| 参数校验与通用异常处理 | 必填项没传、参数不合法、业务报错时返回统一错误 |
| 时间格式 | 返回 JSON 时统一日期时间格式 |
| 请求日志 | 记录请求路径、状态、耗时 |
| 健康检查 | 提供 `/health` |

即使一个服务不需要登录、权限或数据库，也可以引用这个模块。

职责速记：**common 管通用请求处理，security 管身份与权限检查，system 管账号和权限数据。**
