# system-service：统一账号与权限管理服务

记住一句话：**维护账号和授权数据，提供登录，告诉其他服务当前用户有哪些权限。**

这是独立运行的服务，默认端口 **8080**，启动入口是 `SystemApplication.java`。它引用 `base-security`，并通过它引入 `base-common`。

| 负责什么 | 例子 |
| --- | --- |
| 登录 | 校验账号密码，用私钥签发 Token |
| 用户管理 | 创建用户、修改用户、分配角色 |
| 角色管理 | 维护角色，给角色分配菜单和操作权限 |
| 菜单与按钮管理 | 保存前端导航、菜单层级和按钮权限绑定 |
| 权限码管理 | 维护 `system:user:list` 等操作权限 |
| 提供最新身份授权 | `/auth/access` 供业务服务查询当前用户、角色和权限 |

账号、角色、菜单、权限数据保存在这个服务连接的数据库里。前端向它登录、获取菜单，再携带同一个 Token 请求其他业务服务。

建表 SQL 集中在根目录的 [数据库脚本](../sql/README.md)，按发布版本分目录。当前 V1 由本服务的 POM 打包，启动时通过 Flyway 自动执行。

例如用户访问亲友服务：亲友服务使用 security 检查 Token，向 system 查询最新授权，然后处理自己的业务。

职责速记：**common 管通用请求处理，security 管身份与权限检查，system 管账号和权限数据。**

具体配置和启动步骤见 [项目说明](../README.md) 与 [基础规范与运行说明](../docs/基础规范与运行说明.md)。
