# Java 学习流程

本目录记录当前项目的学习过程。每次学习只推进一个小步骤，先自己操作，再记录结果。

当前代码的功能与每个文件用途见 [当前项目功能与文件说明](当前项目功能与文件说明.md)。下表记录你亲自练习的进度；早期示例与当前基础管理代码的差异，以现状说明为准。

当前运行入口已拆成 system（8080）和 relations（8081），见 [IDEA配置与运行流程](../IDEA配置与运行流程.md)。数据库准备和 Neon 学习过程见 [启动报错与数据库配置](启动报错与数据库配置.md)；数据库现归 system，JWT_SECRET 已改为 RSA 公私钥配置。亲自操作的进度仍以下表记录为准。

本机配置进度：已填写 Neon 数据库配置、生成 RSA 密钥并添加 `SystemApplication-local`、`RelationsApplication-local` 两个 IDEA 运行项。Java JDBC 只读连接已验证成功；8081 亲友服务的 `/health` 已返回 HTTP 200。8080 统一管理服务目前无法连接，启动与 Flyway 建表待确认。

## 后续记录方式

1. 每个学习步骤使用「编号_学习主题.md」命名，在本表登记入口。
2. 每篇只记录：目的、操作步骤、成功标志、实际遇到的问题与解决办法。
3. 根据你的实际操作结果更新状态；未操作或未验证的内容不标为完成。
4. 当前问题优先补充到对应步骤，方便以后按主题查找。
