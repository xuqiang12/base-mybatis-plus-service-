## 目的

知道程序从哪里启动，并通过浏览器确认接口可以访问。

## 第一步：认识已有文件

| 文件或目录 | 作用 |
| --- | --- |
| 根目录 `pom.xml` | Maven 配置：管理模块、依赖和版本 |
| `base-common` | 共用代码模块，本身不启动服务 |
| `relations-service` | 提供接口的业务服务 |
| `RelationsApplication.java` | 程序启动入口 |
| `HealthController.java` | 处理浏览器发来的 `/health` 请求 |
| `ApiResponse.java` | 统一返回格式：`code`、`message`、`data` |
| `application.yml` | 服务配置，当前端口为 `8080` |

当前要求 JDK 21。JDK 用于编译和运行 Java；IDEA 用于写代码和调试；Maven 用于管理依赖和构建；Spring Boot 用于搭建后端服务。

当前只有健康检查接口；数据库和业务增删改查尚未实现。

## 第二步：在 IDEA 中启动

1. 打开整个项目目录 `F:\公司项目\gitee\base-mybatis-plus-service`，等待 Maven 同步完成。
2. 左侧依次展开 `relations-service → src → main → java → com.base.relations`。
3. 打开 `RelationsApplication.java`。
4. 点击 `main` 方法左侧绿色三角形，选择运行 `RelationsApplication`。
5. 控制台出现 `Started RelationsApplication` 后，浏览器打开 `http://localhost:8080/health`。

成功标志：浏览器返回包含以下内容的 JSON（字段顺序可以不同）。

```json
{
  "code": 0,
  "message": "成功",
  "data": {
    "service": "relations-service",
    "status": "UP"
  }
}
```

请求经过：浏览器 → `HealthController.health()` → `ApiResponse` 包装数据 → 返回 JSON。

## 第三步：停止与再次运行

1. 停止：点击 IDEA 运行窗口中的红色停止按钮。
2. 再次运行：选择右上角 `RelationsApplication` 运行配置，点击绿色三角形。

## 遇到问题时先查这里

| 现象 | 下一步 |
| --- | --- |
| 提示 Java 版本不支持 | 检查项目 SDK 和运行配置 JRE 是否为 21；参考下方配置文档 |
| 没有绿色运行按钮 | 确认 Maven 同步完成，打开的是 `RelationsApplication.java` |
| 提示 8080 被占用 | 先检查 IDEA 中是否已启动了本服务 |
| 浏览器打不开接口 | 看控制台是否启动成功；记录具体报错后排查 |

配置参考：[IDEA配置与运行流程](../IDEA配置与运行流程.md)。本机 JDK 21 目录为 `D:\DevTools\jdk-21.0.12.1+1`；当前 PowerShell 默认 Java 为 8，与 IDEA 的配置分别生效。
