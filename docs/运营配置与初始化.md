# 运营配置与初始化

首页装修、页面绑定和底部导航归属 CMS 运营配置。账号、角色和权限属于系统管理，账本和家庭属于礼账业务。当前统一运行在 system-service，不另拆服务。

## 数据位置

`database-seed/src/main/resources/seeds/system-service/cms/` 保存初始默认数据：

| 文件 | 用途 |
| --- | --- |
| home.json | 礼账首页方案及标题、公告、常用入口三个组件 |
| page-bindings.json | home 页面与礼账首页方案的绑定 |
| tabbar.json | 首页、亲友、收支、我的四个真实页面入口及图标、颜色 |
| permissions.json | 12 项 gl:cms:资源:操作权限 |
| menus.json | 运营管理目录与首页装修、页面配置、底部导航三个页面 |
| buttons.json | 三个管理页面的查看、新增、编辑、删除权限关联 |

数据库表为 relations.cms_home_decoration、cms_home_component、cms_page_binding、cms_tabbar_config。组件属性 info 与导航 config 使用 JSONB；组件随方案事务保存，被页面绑定的方案不能删除；导航同时最多启用一份。

`CmsSeedService` 只负责默认值与初始化历史，业务读写由 `modules/cms` 的 Controller、Service 和 Models 负责。静态默认值、读取接口、后台维护分工明确，不依赖小程序进程初始化。

## 如何初始化

使用 JDK 21 构建，在 IDEA 运行 **SeedApplication-local**。也可在项目根目录执行：

```powershell
mvn.cmd -s .mvn/settings.xml verify
./database-seed/seed.ps1 -JavaExecutable "D:/DevTools/jdk-21.0.12.1+1/bin/java.exe"
```

沿用已有本机配置中的 gift_ledger。新建的 V3.21 只添加四张 CMS 表，历史 SQL 保持原文。普通 SystemApplication 启动只执行结构迁移，不执行默认数据初始化。

首次分别记录 cms-home/1（含页面绑定）、cms-tabbar/1、cms-management/1 三个批次。三个 CMS 批次在同一事务内，任何一步冲突失败则全部回滚；已有的 system-base/1、admin-account/1 历史不变。运行入口先完成系统批次，再执行 CMS 批次，两部分各自提交事务。

## 重复执行与已有数据

- 首次匹配首页/导航的稳定 code、页面 pageKey、菜单 path、权限 code 及按钮组合；存在的内容整份保留，不覆盖名称、组件、排序、样式、绑定或停用状态。
- 如果已经有其他启用导航，补入的默认导航处于停用状态，保留当前选择。
- 已完成批次再次运行直接跳过。人工删除组件/按钮、撤权或修改页面绑定后不会被下一次 Seed 恢复。修改 JSON 不会自动更新已完成的数据库，后续增量需另写批次。
- 运营权限和菜单会补入字典，但不会给已有角色增加授权；超级管理员可以直接管理，普通角色由管理员主动分配页面菜单与 gl:cms 权限。
- 页面绑定的方案选择列表需要 gl:cms:home:list，维护页面绑定的角色应同时具备首页方案查看权限。

## 管理与读取

运行更新后的 Java 服务与 Vue 管理端，重新登录或刷新授权，在“运营管理”中维护三个页面：

1. 首页装修：编辑方案名称、场景和启用状态；新增或移除具名组件，选择模板、排序与状态。组件属性用 JSON 对象编辑，非法 JSON 不提交。当前提供配置编辑能力，尚无拖拽画布和实时页面预览。
2. 页面配置：用固定页面标识绑定装修方案。home 为默认首页，绑定和方案都启用才返回配置。标识创建后不能修改，可新增绑定后删除原绑定。
3. 底部导航：编辑方案名称、显示模式、颜色、圆角、根页面和入口列表；入口分别配置名称、图标、选中图标、页面路径及排序。启用一个方案自动停用之前启用的方案，保存失败会回滚。

保存后配置立即供下一次接口读取，不另设发布版本流程。导航编码、装修编码创建后不能修改。

管理接口：GET /cms/home/list、/cms/home/detail，POST /cms/home/save、/cms/home/delete；页面绑定和导航分别使用 /cms/page 与 /cms/tabbar 前缀。详情与列表复用 list 权限，save 根据 id 是否存在检查 add 或 edit，delete 单独检查。

登录用户可读取 GET /cms/client/page?pageKey=home 与 GET /cms/client/tabbar，不需要后台管理权限；未登录返回401，无启用配置返回404。客户端页面只返回启用组件并按 sortNo 排序，导航响应带 id/name 和完整 config 字段。

## 小程序接入边界

默认导航使用礼账项目真实存在的 /pages/index/index、/pages/category/index、/pages/tools/index、/pages/mine/index 与 static/family/tabbar 图标，未加入 AI 或商城示例入口。

当前小程序首页实际运行家庭账本视图；其旧通用装修和导航 API 文件仍通过 Nest 请求。这次完成 Java CMS、Seed 与管理后台，未改小程序的请求地址或家庭首页渲染逻辑，因此后台保存的装修还不会直接改变当前账本首页。后续接入时应单独决定通用装修在哪个页面使用，并验证真实小程序展示效果。

阿里云用户和账本仍未导入，本阶段没有写入阿里云或原 neondb。
