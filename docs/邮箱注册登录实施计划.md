# 邮箱注册与密码登录实施计划

目标：邮箱验证码注册时设置密码；邮箱或绑定的手机号加密码登录；登录后可填写手机号绑定，暂不短信验证。

## 实施步骤与校验

- [x] 先编写 `EmailRegistrationHttpTest`，确认注册接口不存在导致预期失败。
- [x] 新增 V2.2 增量，重命名邮箱验证标记并废止旧用途验证码，保留 V2.1 迁移历史。
- [x] 将原免密码入口替换为 `POST /auth/email/register`，必须提供邮箱、验证码和密码；注册只创建普通用户，禁止覆盖旧账号密码。
- [x] 扩展原 `/auth/login` 接收 `account`（邮箱或手机号）和密码，兼容原 `email` 字段；保留 BCrypt 和 RS256。
- [x] 新增 `/user/bindPhone`，仅修改当前用户，校验格式及数据库唯一性；当前用户信息返回邮箱和手机号。
- [x] 更新 SMTP 示例与中文学习说明。
- [x] 全量测试及 JAR 检查，确认原密码登录、权限、迁移升级和新增注册/绑定行为正常。

验证码继续采用 PostgreSQL、HMAC 摘要和行锁；5 分钟有效、60 秒间隔、邮箱每日 10 次、IP 每日 50 次、5 次错误作废。SMTP 失败计入限额但不覆盖有效旧码。

真实 SMTP、实际 PostgreSQL 迁移和小程序联调需配置后验证，本次不自动执行真实数据库变更。旧版本可能已有无密码测试账号，不能靠重复注册补密码，需通过管理员维护处理。

## 验证结果（2026-10-16）

JDK 21 下 `mvn.cmd -s .mvn/settings.xml clean verify` 成功，共 45 项测试：公共请求处理 4、注册和手机号绑定 17、迁移 3、身份管理 19、单应用授权 2。注册接口测试先失败后通过；历史大小写邮箱兼容用例也先复现 401，再修复为精确匹配优先。

独立只读审查提出的历史邮箱兼容问题已修复并复核，无剩余阻断项。可执行包检查包含 11 份与源码一致的迁移，排除本机配置和 PEM 密钥。
