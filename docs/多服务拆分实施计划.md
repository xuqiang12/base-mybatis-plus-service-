# 多服务拆分实施计划

> 历史记录：2026-10-16 已改为三个 Maven 模块、一个运行应用，只启动 `SystemApplication-local`（8080）。本文旧服务与运行步骤保留作历史学习参考，当前操作以 README、IDEA 配置与运行流程和单服务合并实施计划为准。

> 执行方式：在当前会话逐项实施和自审；用户已批准实施。现有工作目录含用户未提交文件，在该目录精准修改，不提交或重置已有工作。

**Goal:** 实现共用账号权限的两个独立服务和两个公共类库。

**Architecture:** common 保持通用；security 持有认证校验和身份提供接口；system 本地提供身份和管理功能；relations 通过真实 HTTP 获取统一身份授权。

**Tech Stack:** Java 21、Spring Boot 3.5.16、MyBatis-Plus 3.5.17、PostgreSQL、Flyway、Spring Security、RS256。

**Spec:** [统一账号多服务设计.md](统一账号多服务设计.md)

## 约束

- 保留现有 API、响应和管理规则；迁移脚本内容及已有表名不变。
- 不新增实际亲友业务；测试探针仅在测试代码中。
- 私钥只在 system；relations 无数据库依赖和用户管理代码。
- 不加入网关、注册中心、缓存和自动重试。
