# 单服务合并实施计划

日期：2026-10-16。用户已确认将当前双服务改为单服务。

## 设计与边界

- 保留 `base-common`、`base-security` 两个类库和 `system-service` 一个运行模块，唯一入口为 `SystemApplication`，默认端口 8080。
- `relations-service` 当前只有启动和远程身份查询，没有需要迁移的业务功能；移除该模块及运行配置。后续亲友业务放在 `system-service/src/main/java/com/base/system/modules/relations/`，本次不创建空业务代码。
- 安全模块通过 `CurrentUserProvider.currentUser(int userId)` 调用本地 `AccessService`，查询最新用户状态与权限；移除原 Token 转发、远程身份故障分支及内部 `/auth/access` 接口。
- 现有登录、用户、角色、菜单、权限接口与 RSA Token 保留。现有 PostgreSQL 连接、`relations` schema、9 个 Flyway 脚本和本机密钥配置保留，不执行远程数据库初始化。
- 保留工作区已有的 README 礼账规划链接、SystemApplication 本机配置加载参数，以及礼账规划中的业务需求，只同步其服务架构描述。
