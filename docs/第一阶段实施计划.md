# 第一阶段实施计划：搭建可独立运行的 Java 服务基础工程

> 本文保留第一阶段的历史范围。当前结构和运行步骤以 [README](../README.md)、[基础规范与运行说明](基础规范与运行说明.md) 为准。

## 已确认的目标

在当前仓库建立父工程、`base-common` 和 `relations-service`，使用 JDK 21，完成统一返回和健康检查，并验证编译、启动和真实 HTTP 请求。

## 技术与边界

- Spring Boot 3.5.16，Java 21，Maven 3.9。
- 父工程统一管理 MyBatis-Plus 3.5.17 的 Spring Boot 3 starter 版本；本阶段业务服务只启用 Web。
- 公共模块负责统一返回结构，业务服务负责启动和接口。
- 本阶段不连接数据库，不创建表，不实现微信登录、借还款或管理后台。
- 使用独立 JDK 21 执行验证，不修改公司项目使用的系统默认 JDK 8。
- 所有新源码文件和方法添加简短中文职责注释。
- 直接在用户指定的新仓库完成，不创建额外服务，不提交或推送 Git。

## 接口约定

`GET /health` 返回 HTTP 200：

```json
{"code":0,"message":"成功","data":{"service":"relations-service","status":"UP"}}
```

这里的健康检查仅确认 Web 服务可响应，不代表数据库或微信链路可用。
