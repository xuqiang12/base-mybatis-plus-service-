## 未验证事项与剩余操作

1. **真实邮箱**：需要可接收邮件的真实邮箱，在普通实例验证投递、验证码过期与限额；本轮未发送真实邮件。
2. **微信真机**：需要开发者工具、合法域名配置和真机环境，逐页验证登录、金额输入、分享卡片确认加入与返回刷新。
3. **两台物理设备**：需要两名家庭成员各自登录，在一端新增/修改，另一端刷新确认。当前仅以HTTP双身份、自动化和本机H5验证。
4. **域名**：配置域名HTTPS握手失败，未绕过证书。需要在域名所属设备/网络恢复HTTPS服务，再验证domain模式和小程序合法域名；本机8000/9000只监听127.0.0.1。
5. **可选外部CMS**：若还需要维护旧CMS登记，应安装对应Nest兄弟工程后重跑该项跨工程测试；礼账Java闭环不以它作为业务数据源。

以上未验证项目不宣称通过，不以本机测试、构建或截图替代。
