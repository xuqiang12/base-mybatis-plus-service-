# 家庭成员管理当前范围

更新：2026-10-19。

注册时建立单人家庭；已有用户读取家庭时补齐。每个账号一个当前家庭，最多两人。家庭写请求携带 X-Family-Id，事务内按固定顺序锁定家庭并重新校验成员。

## 微信分享邀请

小程序通过微信分享卡片邀请家人。发送者登录后获取后端签名的邀请信息，卡片路径携带 token。接收者打开后登录并返回原邀请，查看邀请者、家庭名称，点击确认加入。

邀请使用现有 RS256 签名和验签能力，独立 subject 为 family-invitation，携带 familyId、inviterId，无定时过期、替换、撤销或使用状态。邀请不能充当登录 Token。卡片可转发，首位符合条件的用户确认后加入。

加入时双方必须为单人家庭，不能接受自己的邀请；校验签名、邀请者仍属于卡片里的家庭及 X-Family-Id。双方迁入新家庭，旧卡片因原家庭成员关系改变而自然失效。双人家庭任一人退出后，退出者拥有新的单人家庭，另一人留在原家庭。

## 接口

- GET /family/state：当前用户和家庭成员，无邀请状态。
- POST /family/invitation/share：返回 {token}。
- GET /family/invitation?token=...：返回 {familyName,inviterName}。
- POST /family/invitation/accept：提交 {token}，返回家庭快照。
- POST /family/leave：返回退出者的新单人家庭快照。
