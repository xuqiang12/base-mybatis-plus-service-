# 礼账完整开发计划

> 本计划依据《礼账真实服务设计》执行；当前工作区已有未提交改动全部保留，不重写历史迁移。

## 总验收标准

登录后创建的数据可在刷新、重新登录和另一设备恢复；Mock 仅在显式 Mock 模式运行；真实模式请求失败不会显示成功或回退 Mock；跨家庭查询、修改、删除被拒绝；前端页面统计与后端汇总口径一致。

## 阶段一：真实服务与 Mock 分离

**功能**：核实 Java 端口、Flyway 位置、H5 代理和 local/domain 地址；统一 `src/api/helper/http.ts` 的 Java 地址与认证；让 `src/api/giftLedger.ts`、`src/api/family.ts` 在非 Mock 模式只走真实 HTTP，未接入方法明确失败提示。

**文件范围**：后端 `README.md`、`docs/基础规范与运行说明.md`；前端 `src/api/helper/http.ts`、`src/api/giftLedger.ts`、`src/api/family.ts`、`src/store/environment.ts`、相关环境文件和 `tests/environmentMode.test.cjs`、`tests/apiSourceContract.test.cjs`。

**验收**：三种环境地址显示正确；Mock 模式不发 HTTP；local/domain 模式不引用 Mock；无 Token、401、5xx、超时均显示失败并保留错误对象；已有登录/家庭/亲友测试通过。

## 阶段二：亲友管理

**功能**：复用 `/friend/create|list|detail|update|delete`；接通分页、搜索、详情、修改、删除；统一 `gender` 0/1/2 与页面字符串、`remark`/`note`、字符串 ID；新增后重新加载从数据库恢复。

**文件范围**：后端 `system-service/modules/friend`、`sql/1.0.2/V3_3__friend.sql` 只补必要契约；前端 `src/api/giftLedger.ts`、`src/api/friend.ts`（如需拆分）、`src/store/gift.ts`、`src/pages-sub/record/friends/list.vue`、`src/pages-sub/friends/form.vue`、`src/pages-sub/friends/detail.vue`、`src/types/giftLedger.ts`；测试 `FriendHttpTest` 与 `tests/friendBackend.test.cjs`、`tests/giftFriendManage.test.cjs`。

**验收**：分页和姓名搜索契约一致；修改、删除后列表和详情一致；刷新、重新登录可取回；同家庭成员可见；跨家庭 ID 被拒绝。

## 阶段三：账簿与人情往来

**后端表/接口**：新增账簿、流水 Flyway 迁移；`modules/ledger/book` 和 `modules/ledger/gift` 提供新增、查询、修改、删除、汇总。人情保存 `family_id`、可空 `friend_id/book_id`、事件、方向、金额分、业务日期、姓名/称谓快照和记录人快照。未选亲友时在同一事务创建亲友和流水；收礼可关联账簿，送礼不关联。删除账簿解除关联并保留流水。

**前端文件**：`src/api/giftLedger.ts`、`src/store/gift.ts`、`src/types/giftLedger.ts`、`src/pages-sub/record/books/*`、`src/pages-sub/record/gift-form.vue`、`src/pages-sub/record/friends/list.vue`、`src/pages-sub/friends/detail.vue`、首页/统计使用处；保留现有视觉规范。

**验收**：账簿增删改查和收礼汇总真实持久化；人情新增支持已有/新建亲友事务；亲友汇总、往来明细、账簿汇总不混入借贷；删账簿后流水仍显示且归属为空；金额使用整数分；新增、修改、删除后相关页面刷新一致。

## 阶段四：借贷管理

**后端表/接口**：新增 `loan_record` 迁移和 `modules/ledger/loan`；支持 `lend/receive/borrow/pay`，按亲友分别计算待收、待还；收款/归还事务内锁定并重算，金额超额或并发冲突返回业务错误。已确认未结清借贷禁止删除亲友。

**前端文件**：`src/api/giftLedger.ts`、`src/store/gift.ts`、`src/pages-sub/record/loan-form.vue`、`src/components/loan-record-form/*`、亲友列表/详情和统计页面、类型及测试。

**验收**：借出 100 元、收回 30 元后待收 70 元，再收 80 元失败；借入/归还同理；借贷汇总与人情金额分离；未结清亲友删除显示明确提示；历史列表和刷新恢复正确。

## 阶段五：月度家庭收支

**后端表/接口**：新增分类表和月度记录表迁移；以 `family_id + month` 唯一键保证一月一表，分类明细保存月度合计；分类支持新增、改名、启停、排序，已有记录使用过的分类禁止删除；方向和分类必须一致。

**前端文件**：`src/api/giftLedger.ts`、`src/store/gift.ts`、`src/types/giftLedger.ts`、`src/pages-sub/record/house-form.vue`、`src/pages-sub/household/categories.vue`、`src/pages-sub/household/category.vue`、`src/pages-sub/household/detail.vue`、`src/utils/household.ts`、相关组件及测试。

**验收**：同家庭同月只有一条记录；再次打开可修改原记录；分类维护和删除限制生效；月度明细、月度分类、年度月度、年度分类统计口径一致；收入、支出、结余、存款分别正确。

## 阶段六：首页与我的统计

**功能**：新增后端首页汇总接口或组合查询，返回存款、当月收支、结余、待收待还、趋势、分类排行、最近记录和数量；分页列表不影响总计；前端补齐加载、空状态、失败重试、刷新和写入后的局部更新。

**文件范围**：后端 `modules/ledger/summary`（或沿用现有 home 模块）；前端 `src/api/home.ts`、首页、我的、统计相关页面和 store；测试 `ledgerHome.test.cjs`、`minePage.test.cjs` 及后端汇总 HTTP 测试。

**验收**：首页和明细页面使用同一口径；新增/修改/删除后统计刷新；服务失败不显示旧成功提示；空家庭显示空状态。

## 阶段七：家庭共享与完整验收

**功能**：所有业务 SQL 带家庭条件；加入不迁移双方旧数据；退出者获得新空家庭，原家庭数据保留给原家庭成员；复核邀请、确认加入、退出和两人上限；不上传本机旧账、不导入演示数据。

**文件范围**：后端 `modules/family`、所有礼账 Service/Mapper、共享迁移/测试；前端 `src/api/family.ts`、`src/store/family.ts`、家庭页面及全流程测试。

**验收**：两名成员互相可见新增/修改；刷新或重新登录可看到对方更新；跨家庭资源访问统一拒绝；加入/退出不复制、清空或制造无入口数据；真实接口联调完成。

## 每阶段验证命令

- 后端：`mvn.cmd -s .mvn/settings.xml -B -ntp test`，必要时执行 `clean verify` 和真实 PostgreSQL smoke。
- 前端：`node --test tests/*.test.cjs`、`npm.cmd run type-check`、`npm.cmd run build:h5`、`npm.cmd run build:mp`。
- 联调：启动 Java `system-service`（当前 8000）和 UniApp H5，使用真实登录账号逐项执行阶段验收清单。
